# Get available views in atlas

Get available views in atlas

## Usage

``` r
atlas_views(atlas)

brain_views(atlas)
```

## Arguments

- atlas:

  A `ggseg_atlas` object

## Value

Character vector of view names, or NULL if no sf data

## Examples

``` r
atlas_views(aseg())
#> [1] "axial_3"   "axial_4"   "axial_5"   "axial_6"   "coronal_1" "coronal_2"
#> [7] "sagittal" 
atlas_views(tracula())
#> [1] "coronal"        "inferior_axial" "mid_axial"      "sagittal"      
#> [5] "superior_axial"
```
